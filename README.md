# 🎙 Silero TTS Studio

Профессиональная среда (GUI) для генерации аудиокниг, подкастов и озвучки текста с использованием нейросети Silero. 

Программа разработана для создания длинных аудиокниг с минимальными затратами API-лимитов. Поддерживает умное кэширование, локальную постобработку звука (FFmpeg), работу с глоссариями, импорт электронных книг (EPUB, FB2, DOCX) и пакетную сборку (склейку) файлов с ID3-тегами.

---

## 🚀 Основные возможности

* **🎨 Современный адаптивный UI (v1.2):** Мгновенное переключение тем `sv-ttk` (Светлая / Темная) **на лету без перезапуска программы**. Адаптивная палитра статусов (Material Design) исключает напряжение глаз в темноте и автоматически подгоняет цвета таблиц и меток под выбранный режим.
* **Мгновенная склейка (Zero-RAM Concat):** Новое ядро склейки через FFmpeg Concat Demuxer сшивает аудиокниги любого объема за считанные секунды с нулевым потреблением ОЗУ.
* **Атомарный кэш (Atomic Save):** Запись индекса во временные файлы исключает повреждение JSON при сбоях. Поддерживаются независимые режимы LRU (по количеству) и TTL (по времени жизни).
* **Импорт книг:** Извлечение текста и метаданных автора из `.epub`, `.fb2`, `.docx` с поддержкой гибких шаблонов нумерации (`{num:0}`, `{num:15}`, `{author}`, `{title}`) и умная нарезка `.txt` по регулярным выражениям.
* **Постобработка звука:** Локальное изменение скорости (Tempo), тона (Pitch) и эха (Reverb) без повторной траты API-кредитов.
* **🎵 Сборщик книг и Экспорт (v1.2):**
  * Поддержка одиночных файлов в Корне и древовидных Групп (Томов).
  * Человеческая натуральная сортировка (`Глава 2` всегда идет перед `Глава 10`).
  * Многопоточный фоновый импорт тысяч файлов с пакетным обновлением интерфейса без зависаний.
  * Авто-разбивка на тома по длительности (например, по 60 минут), извлечение обложек, удобная сетка 2х2 с динамической блокировкой кнопок для массового применения ID3-тегов.
* **Контроль CPU:** Настройка параллельных потоков кодирования (от режима максимальной скорости до "тихого/холодного" режима для ноутбуков).
* **🍏 Нативная интеграция с macOS (v1.2):** Прямое взаимодействие с системным буфером обмена (`pbcopy`/`pbpaste`) гарантирует работу комбинаций `⌘C`, `⌘V`, `⌘X`, `⌘A`, `⌘Z` при любой раскладке клавиатуры.
* **🔕 Бесшумность на Windows (v1.2):** Фоновые вызовы FFmpeg и ffprobe скомпилированы с автоматическим подавлением всплывающих консольных окон (`CREATE_NO_WINDOW`).

## ⚙️ Установка и запуск

Для работы программы необходим **Python 3.8+** и системный пакет **FFmpeg** (для работы со звуком и извлечения обложек).

### Шаг 1. Установка FFmpeg (Обязательно)
* **Windows:**
  1. Скачайте архив с FFmpeg (например, с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/)).
  2. Распакуйте его в удобное место (например, `C:\ffmpeg`).
  3. Добавьте путь к папке `bin` (например, `C:\ffmpeg\bin`) в системные переменные среды `PATH`.
* **macOS:**
  Для поддержки кодека Vorbis (OGG), который использует Silero, установите расширенную версию через Homebrew:
  ```bash
  brew tap homebrew-ffmpeg/ffmpeg
  brew install homebrew-ffmpeg/ffmpeg/ffmpeg
  ```
* **Linux (Ubuntu/Debian):**
  ```bash
  sudo apt update && sudo apt install ffmpeg
  ```

### Шаг 2. Установка зависимостей Python
Откройте терминал в папке с программой и выполните:
```bash
pip install sv-ttk requests pydub razdel ru-normalizr EbookLib beautifulsoup4 python-docx lxml
```
или скачайте файл `requirements.txt` и выполните:
```bash
pip install -r requirements.txt
```
*Примечание для Linux:* Убедитесь, что в системе установлена библиотека Tkinter (`sudo apt install python3-tk`).

### Шаг 3. Запуск
```bash
python3 SileroTTS_Studio.py
```

## 🖥 Особенности работы на разных ОС

* **macOS (.app & .py):** Из-за ограничений безопасности Apple (Gatekeeper) скомпилированное приложение создает структуру проекта в `~/Documents/SileroTTS_Studio/`. Поддерживаются нативные горячие клавиши `⌘C`, `⌘V`, `⌘X`, `⌘A`, `⌘Z` и атомарный мультивыбор мышкой через `⌘-Click`.
* **Windows:** Бесшумная работа фоновых утилит — окна командной строки не моргают при генерации и сборке.
* **Portable-режим:** При запуске `.py` файла из консоли на любой ОС или `.exe` на Windows программа работает в полностью портативном режиме (все рабочие папки создаются строго рядом со скриптом).
