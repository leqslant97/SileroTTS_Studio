# 🎙 Silero TTS Studio

Профессиональная рабочая среда (GUI) для генерации аудиокниг, подкастов и озвучки текста с использованием нейросети Silero. 

Программа разработана для создания длинных аудиокниг с минимальными затратами API-лимитов. Поддерживает умное кэширование, локальную постобработку звука (FFmpeg), работу с глоссариями, импорт электронных книг (EPUB, FB2, DOCX) и пакетную сборку (склейку) файлов с редактированием ID3-тегов.

---

## 🚀 Основные возможности

* **Мгновенная склейка (Zero-RAM Concat):** Новое ядро склейки через FFmpeg Concat Demuxer сшивает аудиокниги любого объема за считанные секунды с нулевым потреблением ОЗУ.
* **🏷️ In-Place Тегирование (Новое в v1.3):** Уникальный режим *"Только обновить теги (в исходных файлах)"* мгновенно перезаписывает метаданные и вшивает обложки прямо в оригинальные файлы на диске **без перекодирования звука** и с нулевой потерей качества.
* **⏱️ Расчет Общего Времени (Новое в v1.3):** В шапке дерева экспорта в реальном времени отображается точная суммарная длительность всех аудиофайлов проекта (`HH:MM:SS`).
* **⚙️ Массовое применение настроек групп (Новое в v1.3):** Диалоговое окно *"Применить ко всем группам..."* позволяет в 1 клик скопировать параметры склейки, подпапок и пауз на все тома и сохранить их по умолчанию.
* **📂 Память путей и Авто-заполнение (Новое в v1.3):** Программа автоматически подставляет путь исходного файла в поле экспорта и имеет единую память каталогов между кнопками *"Добавить аудио"* и *"Добавить папку"*.
* **📊 Плавный пофайловый прогресс-бар (Новое в v1.3):** Прогресс-бар рендеринга отображает статус для каждого отдельного аудиофайла, а не только при смене групп.
* **Атомарный кэш (Atomic Save):** Запись индекса во временные файлы исключает повреждение JSON при сбоях. Поддерживаются независимые режимы LRU (по количеству) и TTL (по времени жизни).
* **Импорт книг:** Извлечение текста и метаданных автора из `.epub`, `.fb2`, `.docx` с поддержкой гибких шаблонов нумерации (`{num:0}`, `{num:15}`, `{author}`, `{title}`) и умная нарезка `.txt` по регулярным выражениям.
* **Постобработка звука:** Локальное изменение скорости (Tempo), тона (Pitch) и эха (Reverb) без повторной траты API-кредитов.
* **Сборщик книг и Экспорт:**
  * Поддержка одиночных файлов в Корне и древовидных Групп (Томов).
  * Человеческая натуральная сортировка (`Глава 2` всегда идет перед `Глава 10`).
  * Многопоточный фоновый импорт тысяч файлов с пакетным обновлением интерфейса без зависаний.
  * Авто-разбивка на тома по длительности (например, по 60 минут), извлечение обложек, удобная сетка 2х2 для массового переноса ID3-тегов.
* **Контроль CPU:** Настройка параллельных потоков кодирования (от режима максимальной скорости до "тихого/холодного" режима для ноутбуков).
* **🍏 Нативная интеграция с macOS:** Прямое взаимодействие с системным буфером обмена (`pbcopy`/`pbpaste`) гарантирует работу комбинаций `⌘C`, `⌘V`, `⌘X`, `⌘A`, `⌘Z` при любой раскладке клавиатуры.
* **🛡️ Пуленепробиваемая кроссплатформенность (v1.3):**
  * **Windows 11:** Автоматическая зачистка кавычек при вставке путей через функцию *"Копировать как путь"*.
  * **Linux/macOS:** Автоматическое декодирование путей с префиксами `file://` и процентами `%20`.
  * **NullWriter:** Глобальный патч защищает Portable-версии от тихих вылетов PyInstaller при сборках с флагом `--windowed` / `--noconsole`.

## ⚙️ Установка и запуск

Для работы программы необходим **Python 3.8+** и системный пакет **FFmpeg** (для работы со звуком и извлечения обложек).

### Шаг 1. Установка FFmpeg (Обязательно)
* **Windows:**
  1. Скачайте архив с FFmpeg (например, с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/)).
  2. Распакуйте его в удобное место (например, `C:\ffmpeg`).
  3. Добавьте путь к папке `bin` (например, `C:\ffmpeg\bin`) в системные переменные среды `PATH`.
* **macOS:**
  Для поддержки кодека Vorbis (OGG), который использует Silero, установите расширенную версию через Homebrew:
  ```bash
  brew tap homebrew-ffmpeg/ffmpeg
  brew install homebrew-ffmpeg/ffmpeg/ffmpeg
  ```
* **Linux (Ubuntu/Debian):**
  ```bash
  sudo apt update && sudo apt install ffmpeg
  ```

### Шаг 2. Установка зависимостей Python
Откройте терминал в папке с программой и выполните:
```bash
pip install requests pydub razdel ru-normalizr EbookLib beautifulsoup4 python-docx lxml
```
или скачайте файл `requirements.txt` и выполните:
```bash
pip install -r requirements.txt
```
*Примечание для Linux:* Убедитесь, что в системе установлена библиотека Tkinter (`sudo apt install python3-tk`).

### Шаг 3. Запуск
```bash
python3 SileroTTS_Studio.py
```

## 🖥 Особенности работы на разных ОС

* **macOS (.app & .py):** Из-за ограничений безопасности Apple (Gatekeeper) скомпилированное приложение создает структуру проекта в `~/Documents/SileroTTS_Studio/`. Поддерживаются нативные горячие клавиши `⌘C`, `⌘V`, `⌘X`, `⌘A`, `⌘Z` и атомарный мультивыбор мышкой через `⌘-Click`.
* **Windows:** Бесшумная работа фоновых утилит — окна командной строки не моргают при генерации и сборке (`CREATE_NO_WINDOW`).
* **Portable-режим:** При запуске `.py` файла из консоли на любой ОС или `.exe` на Windows программа работает в полностью портативном режиме (все рабочие папки создаются строго рядом со скриптом).
